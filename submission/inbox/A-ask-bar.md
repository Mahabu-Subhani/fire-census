# Draft for the project page: the Ask page

Feeds the "Project details" field (how it works, who it is for) and the demo.
Nothing here is a result; there are no numbers to re-read.

**One box for people in a hurry.** Not every responder wants a dashboard. The
Ask page is a single text box: type a place and a time in plain words, such as
"Sangrur October 2023" or "Río Cuarto from 2015 to 2020", and the parts the app
understood change colour as you type. Press Enter and the map, the calendar and
the downloads open on exactly that district and period.

**Not an AI model.** The box matches district names, months and years by fixed
rules that run in the browser. It sends nothing anywhere and it never writes an
answer: it only sets the same controls a visitor could set by hand, so every
number on screen still comes from the harmonized record. A place outside the
four processed areas is refused in words, not guessed.

Demo idea (for Charulekha to take or leave): open on `?v=ask`, type one
question, press Enter. About five seconds of the thirty.
